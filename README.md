# رياضياتي — Interactive Mathematics Grade 5

منصة تفاعلية للرياضيات للصف الخامس، عربية أولاً وباتجاه RTL. تحتوي المنصة حالياً على سبعة دروس حقيقية من الكتاب المدرسي ضمن الوحدة الأولى:

1. **شبكة الإحداثيات** (ص 3–4)
2. **التمثيلات البيانية بالخطوط** (ص 7–9)
3. **الأعداد الطبيعية** (ص 10–14)
4. **تقريب الأعداد الطبيعية** (ص 15–18)
5. **جمع الأعداد الطبيعيّة وطرحها** (ص 19–22)
6. **قياس الزوايا** (ص 23–30)
7. **متوازي الأضلاع** (ص 31–35)

كل درس مبني على تسلسل خطوات (`LessonShell` → `LessonOutline` → خطوة واحدة في كل مرة)، مع محتوى أصلي من الكتاب، وشرح تعليمي موسّع، وتفاعلات حقيقية، واختبار ختامي جديد، ومنطقة مدرّس منفصلة بالحلول الكاملة ومصدر كل عنصر (رقم صفحة الكتاب أو "نشاط منصة").

## التقنية

- React + TypeScript + Vite
- CSS مخصص بتصميم responsive (من دون إطار UI ثقيل)
- GitHub Actions وGitHub Pages للنشر الثابت
- `MathExpression` يعزل الترميز الرياضي في سياق LTR مع `unicode-bidi: isolate`

## التشغيل المحلي

```bash
npm install
npm run dev
```

للتحقق من الأنواع وبناء الإنتاج:


## GitHub Pages

يستخدم Vite قاعدة النشر `/Interactive-Mathematics-Grade5/`. عند الدفع إلى `main` أو تشغيل workflow يدوياً، يقوم `.github/workflows/deploy.yml` بالتثبيت والتحقق والبناء ثم يرفع `dist` كـ Pages artifact وينشره عبر `actions/deploy-pages`.

لا يعتمد المشروع على مسارات خادم أو قاعدة بيانات. الصفحة الحالية تستخدم روابط داخلية بسيطة، لذلك تبقى متوافقة مع الاستضافة الثابتة.

## إضافة الدروس لاحقاً

- عرّف الوحدات والدروس في `src/content/registry.ts` باستخدام `UnitMeta` و`LessonMeta` (المحتوى/الميتاداتا فقط).
- اربط معرّف الدرس بمكوّنه في `src/content/lessonComponents.tsx` — هذا هو المكان الوحيد الذي يحتاج تعديلاً لإضافة درس جديد للتنقل.
- ضع بيانات كل درس (نقاط، جداول، سلاسل رسم بياني) في ملف بيانات مستقل بجانب الدرس (مثل `lineGraphsData.ts`)، وضع حلول المدرّس في `src/teacher/lessonN.ts`، ولا تستبدل نص الكتاب بملخصات.
- أنشئ تجربة الدرس من مكونات مشتركة (`LessonShell`, `LessonOutline`, `SourceCard`, `CoordinatesGrid`/`LineChart`) بدلاً من صفحة مخصصة ضخمة، بحيث يظهر خطوة واحدة فقط في كل مرة.
- استخدم `MathExpression` لكل رقم أو معادلة منفردة، و`BidiText` لأي عبارة تخلط نصاً عربياً برمز/رقم (مثل الزوج المرتب `(الجمعة، 17)`).
- أضف فحصاً في `scripts/` (مثل `line-graphs-check.ts`) يتحقق من تغطية الحلول وصحة أرقام صفحات الكتاب لكل درس جديد، وسجّله في `package.json`.

تتضمن البنية حالياً `LessonShell` و`LessonOutline` ومكونات الأنشطة و`TeacherArea` منفصلة. منطقة المعلم واحدة لكل الدروس (خلف بوابة كلمة مرور مشتركة)، وتعرض تبويباً لكل درس. تستخدم كلمة المرور `somer173` كبوابة client-side كما طُلب. GitHub Pages الثابتة لا توفر مصادقة حقيقية؛ يمكن استبدال البوابة بطبقة هوية خارجية لاحقاً دون تغيير بيانات الحلول أو تجربة الطالب.

## نظام التصميم (PR1)

الطبقة البصرية المشتركة للمنصة (الرئيسية، الترويسة، التذييل، بطاقات الوحدات والدروس) تعتمد Design Tokens عالمية معرّفة في `src/styles.css` على `:root`:

- **اللوحة**: خلفية عاجية دافئة `--bg`، أسطح `--surface`/`--surface-tint`، حبر بثلاث درجات `--text-1/2/3` (كلها WCAG AA)، كحلي أساسي `--navy` + ذهب هادئ `--gold`/`--gold-deep`/`--gold-soft`، وألوان دلالية `--ok/--warn/--err`.
- **البدائيات**: ثلاثة مستويات ظل فقط `--sh-sm/md/lg`، خمس قيم انحناء `--r-sm…--r-full`، سلم مسافات `--sp-1…--sp-8`، وحد أدنى 13px لأي نص في الطبقة المشتركة.
- **فصل المسؤوليات**: الدروس 1–7 تحتفظ بطبقاتها (`lesson.css`، `lesson-six.css`، `lesson-seven.css`) ورموزها القديمة التسعة (`--ink`، `--blue`، …) **مجمّدة بقيمها الأصلية** في `:root` — أي تعديل عليها تمنعه أداة `design-check`. تجربة الدرس (LessonShell/LessonOutline) محفوظة حرفياً في قسم `LEGACY-LESSON-CHROME` بنهاية `styles.css` وستُحدَّث في PR لاحق منفصل.
- **الخطوط** تُحمَّل عبر `<link>` + preconnect في `index.html` (لا `@import` داخل CSS).

```bash

npm run design-check      # حماية نظام التصميم: tokens + تباين AA + تجميد الرموز القديمة + حد 13px
npm run coordinate-check  # اصطلاح شبكة الإحداثيات (الدرس 1)
npm run line-graphs-check # اصطلاح التمثيل البياني بالخطوط + تغطية الحلول (الدرس 2)
npm run lesson-6-check    # تغطية الدرس السادس (ص 23–30)
npm run lesson-7-check    # تغطية الدرس السابع (ص 31–35) + تدقيق هندسي فعلي للرسوم
npm run browser-smoke-test # تفاعل حقيقي عبر jsdom + Testing Library: تنقّل بين الخطوات، الاختبار الختامي، بوابة المدرّس
```

## الدرس السابع — متوازي الأضلاع (ص 31–35)

- بنية تسلسلية من 15 خطوة داخل `LessonShell` (لا صفحة طويلة ولا anchor links).
- 56 عنصراً من الكتاب (تعريفات، خواص، أنشطة، وكل سؤال فرعي في «تحقّق من فهمك» و«تدرّب» ①–⑤) يظهر كل منها فعلياً في منطقة الطالب عبر `<BookTask>` مع شرح خطوة بخطوة وأخطاء شائعة.
- 18 رسماً هندسياً أُعيد بناؤها بـ SVG عبر `GeoFigure` (أسهم التوازي، أقواس الزوايا، علامة الزاوية القائمة، الأطوال، القطران) مع `FigureFrame` للتكبير عند الحاجة.
- 7 أنشطة تفاعلية من إعداد المنصة: فرز الأشكال، مختبر الخواص، نموذج القص والمطابقة، مشغّل خطوات الرسم، تعيين الرأس الرابع، ملء الفراغات، واكتشاف الخطأ.
- اختبار ختامي جديد من 10 أسئلة (غير منقولة من الكتاب) مع حل مفصّل لكل سؤال في منطقة المدرّس.
- `npm run lesson-7-check` لا يكتفي بالميتاداتا: يتحقق من تركيب كل معرّف داخل منطقة الطالب فعلياً، ومن مطابقة رقم الصفحة، ومن وجود حل تفصيلي لكل عنصر، ثم يرسم الدرس في jsdom ويقيس الرسوم هندسياً (توازي الأضلاع المعلّمة، مطابقة الزوايا المطبوعة للزوايا المرسومة، وحدة مقياس الرسم).

# تمارين الوحدة الأولى المطبوعة — سجل المصدر والتنفيذ

## قرار البنية

هذه مجموعة مراجعة مستقلة وليست درساً تاسعاً. يصل الطالب إليها من مدخل **تمارين الوحدة الأولى** في بطاقة الوحدة، عبر مسار `#unit-exercises/unit-1`. لم تُضف المجموعة إلى `curriculumRegistry.lessons` أو `lessonComponents` أو سجل الاختبارات. حلولها في تبويب مستقل **تمارين الوحدة الأولى** داخل منطقة المدرّس، ولا تدخل في منطقة حلول الاختبارات.

## بوابة المصدر

- مصدر المحتوى: الصور الأربع المرفقة في المهمة حصراً.
- الصفحات المطبوعة المفحوصة: **40، 41، 42، 43**، بالترتيب.
- الأسئلة المرقمة: **12**؛ السؤال 1–3 في ص40، و4–6 في ص41، و7–11 في ص42، والسؤال 12 في ص43.
- وحدات الإجابة التي يغطيها سجل التدقيق: **30**. تتضمن 20 فرعاً/بنداً معلّماً بحروف في المصدر، وعشرة مطالب أخرى (بما فيها مطالب أطوال وزوايا منفصلة). لا يُعدّ كل خلية في جدول واحد سؤالاً مستقلاً.
- العناصر البصرية المعاد بناؤها: شبكتا إحداثيات؛ شكل متوازيي الأضلاع في السؤال 5؛ مخططا السؤالين 11 و12؛ تخطيط المطابقة وجدولا البيانات وجدولا الإكمال؛ وثلاثة تخطيطات الجمع العمودي. الإجمالي وفق هذا التصنيف **12 عنصراً بصرياً**.
- القراءة: النصوص والأرقام والرموز والقياسات في الصور واضحة. لا توجد صورة ناقصة أو عنصر غير مقروء.
- ملاحظة مصدرية محفوظة: السؤال 11 لا يطبع وحدة قياس للارتفاع؛ لذلك يذكر الحل القيمة على التدريج (نحو 500) ولا يخترع وحدة.

## سجل التغطية

`unit-one-exercises-coverage.json` هو السجل الآلي القابل للمراجعة. يسجل لكل وحدة إجابة: المعرّف، والصفحة والسؤال والفرع/المطلب، ومدخل صفحة الطالب ومعرّف العنصر الدقيق فيها، وتبويب المدرّس ومعرّف بطاقة الحل، والرسوم ذات الصلة، والإجابة المتحققة، ونتيجتي تدقيق النقل والحل، والتصنيف. يختبر فحص الواجهة وجود مراسي الطالب والمدرّس لجميع الوحدات الثلاثين.

التصنيف الحالي: **FULL 30 / PARTIAL 0 / MISSING 0 / REFERENCE_ONLY 0**. لا توجد إحالة إلى صورة خارجية بدلاً من إعادة بناء رسم مطلوب.

## ملفات التنفيذ والفحوص

- المصدر المطبوع وبنية المهام والبيانات البيانية: `src/exercises/unitOneExercisesData.ts`.
- صفحة الطالب المستقلة والرسوم وإجابات التحقق الذاتي: `src/exercises/UnitOneExercisesPage.tsx` و`src/exercises/unit-one-exercises.css`.
- الحلول التعليمية المفصلة: `src/teacher/unitOneExercises.ts` و`src/teacher/TeacherUnitExercisesView.tsx`.
- تدقيق المصدر والحسابات والربط: `scripts/unit-exercises-check.ts`.
- اختبار الواجهة التفاعلي: `scripts/unit-exercises-ui-check.tsx`، مبني على jsdom وTesting Library؛ ليس اختباراً بصرياً بمتصفح حقيقي.
- حدّث سجل التغطية عمداً فقط بواسطة `npm run unit-exercises-coverage`؛ ويُتحقق منه دون كتابة عبر `npm run unit-exercises-check`.

لا يغيّر هذا القسم تسلسل الدروس الثمانية أو اختبار الوحدة ذي الستين سؤالاً؛ فحص حدود المشروع يثبت بقاء العددين كما هما.
